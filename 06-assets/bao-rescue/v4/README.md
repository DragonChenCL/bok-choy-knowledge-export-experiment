# Bao Rescue v4 visual assets

This directory contains the higher-resolution visual reference set used by the live v4.5+ diagnosis UI.

The deployment workflow extracts `assets.tar.gz` into the public `/assets/bao-rescue/` directory.

Quality gate:
- 1200×900 source per diagnostic image
- WebP optimized for browser use
- no reuse of one image to represent a different diagnostic state
