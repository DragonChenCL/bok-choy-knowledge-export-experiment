# Bao Rescue v3 — Photo-first Guide

Status: review candidate (not yet commercial-approved)

## What changed from v2

v3 replaces the rough diagram-style symptom art with photorealistic AI-generated steamed-bun reference images. The guide is organized around fast visual matching rather than long-form reading.

## Structure

- cover / product promise
- quick symptom atlas
- wrinkled / elephant skin
- collapsed / overproofed
- dense / not fluffy
- wet / pitted / condensation damage
- barely rose / underproofed
- cracked / split top
- 30-second diagnosis flow
- next-batch worksheet

## Image disclosure

The symptom images in this version are AI-generated reference illustrations rendered in a photorealistic food-photography style. They are not documentary photos of real failed batches and must not be represented as such.

## Commercial quality gate

Before sale, review whether each synthetic reference image accurately communicates the symptom strongly enough to help a real user classify a failed batch. If a symptom is visually ambiguous, replace it with a better synthetic reference or a licensed/original real photograph.
