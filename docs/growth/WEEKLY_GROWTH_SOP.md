# Bao Rescue Weekly Growth SOP

This is the repeatable weekly growth loop for Bao Rescue. The order matters: start from fresh demand and current search data, then improve distribution and authority, then review conversion.

## 1. Monday — Data review and one weekly bet

Use the most recent data first:
- Last 30 days: primary decision window
- Last 90 days: trend confirmation
- Older data: context only

Check:
- Google Search Console: impressions, clicks, CTR, average position by page
- GA4: organic sessions, landing pages, diagnosis starts/completes, premium funnel
- Reddit/community: posts from the last 7–30 days, max 90 days unless still active
- Current SERP: wording, intent, competing content types

Pick ONE weekly topic/page to push. Prefer pages that already have:
- meaningful impressions
- average position 4–20
- weak CTR
- or clear diagnosis/purchase intent

## 2. Tuesday — Improve the primary SEO + GEO page

For the weekly target:
- improve title and meta description for CTR
- keep title/H1 aligned with the real query language
- answer the core question immediately
- add evidence beside important claims
- include limits / when advice may not apply
- add useful internal links
- keep diagnosis CTA visible
- preserve canonical, schema, sitemap and analytics

Do not create a near-duplicate page if an existing page already targets the intent.

## 3. Wednesday — Strengthen the topic cluster

Do one of:
- improve 1–2 related existing pages
- add a genuinely missing supporting page
- improve internal links between pillar, process and symptom pages

Prefer upgrading pages already receiving impressions over publishing more zero-impression pages.

## 4. Thursday — Distribution

Create 3–5 useful external touchpoints from the same core content:
- Reddit/helpful community reply
- social post or visual comparison
- relevant forum/Q&A response
- internal hub link
- short-form content idea

Community rule:
- 70% pure help
- 20% experience / discussion
- 10% natural Bao Rescue mention

Reddit priority:
7 days > 30 days > 90 days.
Check that the post is still open and active before replying.

## 5. Friday — Authority / backlinks

Find 5–10 highly relevant prospects:
- bao / steamed-bun recipe publishers
- Asian cooking sites
- baking troubleshooting resources
- cooking-tool/resource directories

Outreach should reference a specific page on their site and explain why Bao Rescue helps their readers. Do not ask for a generic backlink.

Target outcome:
2–5 new relevant referring domains per month.

## 6. Weekend — Funnel review

Track the chain:
GSC impressions
→ organic clicks
→ landing page
→ diagnosis view
→ diagnosis start
→ diagnosis complete
→ premium offer
→ checkout
→ purchase

Page actions:
- impressions up, CTR low → improve title/meta
- clicks up, diagnosis low → improve content/CTA match
- position 11–30 → strengthen content/internal links/backlinks
- 30–60 days no impressions → deprioritize
- diagnosis + purchase → highest priority to scale

## Weekly KPI snapshot

Record only:
- Google impressions
- Google organic clicks
- top pages / keywords
- new referring domains
- diagnosis starts
- diagnosis completes
- purchases
- best-performing landing page

## Rule for decisions

Fresh data wins:
30 days > 90 days > historical average.

The goal is not content volume. The goal is to find and scale the path that produces:
search/community demand → qualified visit → diagnosis → purchase.
