# Action Log — PDF v1 Rejected

Date: 2026-09-07

## User feedback
The first Bao Rescue PDF was rejected as something the user personally would not buy.

Specific feedback:
- layout quality was poor;
- no useful images;
- customers need image + text to solve the problem quickly.

## Interpretation
This is not cosmetic feedback. It invalidates the previous product format assumption.
The experiment was drifting from 'decision compression' back toward a text-heavy guide.

## Action taken
1. Marked PDF v1 as **not commercially approved**.
2. Created `02-product/exp-003-visual-diagnostic-redesign.md`.
3. Changed the target deliverable to an image-first visual diagnostic product.
4. Kept the current PDFs as experiment artifacts for retrospective review, but they must not be treated as sale-ready assets.
5. Verified the current website state: source exists under `/site`, but the project documentation explicitly prevents deployment until the placeholder checkout URL and domain are replaced.
6. Re-checked the saved Gavin methodology material for a named payment provider. The saved report discusses payment/tax/delivery validation but does not name one specific provider.

## New quality gate
No commercial launch until:
- major symptoms have visual references;
- first-page diagnosis works within ~30 seconds;
- the guide looks meaningfully better than a free FAQ;
- commercial images are original/generated/licensed rather than copied from community posts.

## Payment-provider note
Prior discussion around the project has included Gumroad and Lemon Squeezy. Do not attribute either platform to Gavin unless an original Gavin source explicitly names it.
