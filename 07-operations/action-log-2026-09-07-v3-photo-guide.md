# Action Log — Bao Rescue v3 Photo Guide

Date: 2026-09-07

## Trigger
User rejected the v2 visual guide as still too rough and explicitly requested realistic images, allowing AI-generated images.

## Actions
1. Rebuilt the visual system around photorealistic, consistent food-reference images.
2. Generated a successful/normal steamed-bun reference plus failure references for wrinkling, collapse, dense crumb, condensation damage, underproofing, overproofing/spreading, and cracking.
3. Rebuilt the guide into a 10-page photo-first diagnostic PDF.
4. Kept text deliberately short: symptom recognition -> what to check -> one-variable next-batch test.
5. Added a disclosure that the photos are AI-generated diagnostic references, not documentary images from real failed batches.
6. Rendered the PDF to page images and visually inspected the contact sheet for clipping, overlap, and obvious layout defects.
7. Created a compressed repository copy for version history while keeping the higher-resolution working PDF as the production artifact.

## Product lesson
Visual knowledge products must not merely contain images. The image must materially reduce diagnosis time. For this experiment, the commercial value proposition is fast visual classification and decision compression, not the number of pages.

## Current decision
v3 is a substantially stronger review candidate than v1/v2, but remains subject to user commercial-quality review before checkout/payment setup.
