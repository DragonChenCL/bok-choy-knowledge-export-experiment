# Bok Choy Knowledge Export Experiment

> EXP-001: Can a zero-audience operator use evidence-driven research, AI-assisted production, SEO, and community distribution to sell a useful English knowledge product to overseas home gardeners?

## Current experiment

**Topic:** Bok choy pest diagnosis and rescue for beginner home gardeners.

**Working product hypothesis:** A compact visual decision guide that starts from visible damage (holes, curling, sticky leaves, missing seedlings, etc.), helps the reader narrow likely causes, and tells them what to inspect and what to do next using evidence-backed IPM-oriented guidance.

This is **not yet a validated product**. It is a hypothesis under test.

## Operating rule

Every material action must be traceable to evidence. We do not promote assumptions to facts because an LLM already “knows” them. Important claims are cross-checked against current public web sources, with preference for university Extension, government/agricultural institutions, primary platform listings, and direct community discussions.

Every action and decision is logged so the experiment can be reviewed later.

## Experiment goal

The first meaningful commercial milestone is **one payment from a stranger**. Before that milestone, scale questions (many sites, many personas, account matrices, automation at portfolio scale) are deliberately deferred.
